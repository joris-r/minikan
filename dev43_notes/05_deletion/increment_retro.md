# deletion: increment retrospective

Proposed changes to the Dev43 process. Target: the Dev43 plugin.

## Open the next phase after an exit commit

What happened: after the Tests exit commit, the agent stopped without
loading the Implementation skill or opening its Exploration; the human
had to ask why nothing followed. After the Specification exit commit,
it had done so unprompted: nothing in the rules says which is expected.

Proposal, in the `CLAUDE.md` template, under "State and gates": "After
an exit commit, load the next phase's skill and open its Exploration in
the same turn." Applied to this project's `CLAUDE.md` meanwhile.
